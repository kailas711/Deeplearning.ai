# Deeplearning.ai Repository

This repository contains code materials primarily derived from **DeepLearning.AI** short courses, focusing on various frameworks, concepts, and practical tools in **Deep Learning** and **AI**.

Each folder corresponds to a specific course topic. Inside, you’ll find:
- **Jupyter Notebooks**: Used during exercises, lectures, and assignments
- **Python Files**: Scripts for projects and practice
- Mini-projects exploring core concepts and real-world applications.

## 📂 Repository Overview

Below is an overview of the key folders and their topics:

1. **[Advanced Retrieval with ChromaDB](https://github.com/kailas711/Deeplearning.ai/tree/main/1.%20Advanced%20Retrieval%20with%20ChromaDB)**  
   Learn to leverage **ChromaDB** for advanced information retrieval tasks.
   
2. **[LangChain For LLM Application Development](https://github.com/kailas711/Deeplearning.ai/tree/main/2.%20LangChain%20For%20LLM%20Application%20Dev)**  
   Dive deep into **LangChain** to develop robust Large Language Model (LLM)-powered applications.

3. **[LangChain: Chat With Your Data](https://github.com/kailas711/Deeplearning.ai/tree/main/3.%20LangChain%20Chat%20with%20your%20Data)**  
   Learn how to build chatbots capable of interacting with your custom datasets using **LangChain**.

4. **[LangChain Functions, Tools & Agents](https://github.com/kailas711/Deeplearning.ai/tree/main/4.%20LangChain%20Functions%20Tools%20%26%20Agents)**  
   Explore the integrations and tools available within **LangChain** to enhance LLM outputs.

5. **[Long-Term Agentic Memory With LangGraph](https://github.com/kailas711/Deeplearning.ai/tree/main/5.%20Long-Term%20Agentic%20Memory%20With%20LangGraph)**  
   Discover how **LangGraph** enables long-term memory for AI agents by persisting context.

6. **[Computer Use with Anthropic](https://github.com/kailas711/Deeplearning.ai/tree/main/6.%20Computer%20Use%20with%20Anthropic)**  
   Study practical AI-driven workflows using **Anthropic’s AI tools**.

7. **[MCP - Build Rich-Context AI Apps with Anthropic](https://github.com/kailas711/Deeplearning.ai/tree/main/7.%20MCP%20Build%20Rich-Context%20AI%20Apps%20with%20Anthropic)**  
   Build applications embedding contextual metadata by leveraging Anthropics' advanced LLM technology.

8. **[AI Agents in LangGraph](https://github.com/kailas711/Deeplearning.ai/tree/main/8.%20AI%20Agents%20in%20LangGraph)**  
   Develop AI agents capable of advanced reasoning and memory organization using **LangGraph**.

9. **[Pydantic for LLM Workflow](https://github.com/kailas711/Deeplearning.ai/tree/main/9.%20Pydantic%20for%20LLM%20Workflow)**  
   Optimize data validation and serialization when working with LLM pipelines using **Pydantic**.

10. **[Prompt Engineering OpenAI](https://github.com/kailas711/Deeplearning.ai/tree/main/Prompt%20Engineering%20OpenAI)**  
    Master **Prompt Engineering** techniques to build performant and versatile OpenAI-driven applications.

    - Features my implementation of a **tiny chatbot** using OpenAI’s `gpt-3.5-turbo`.
